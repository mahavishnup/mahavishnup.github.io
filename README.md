Personal portfolio website for **Mahavishnu Ponnusamy**, Senior Full-Stack Engineer with 6+ years of production experience in Laravel, React.js, FastAPI, and AI platforms.

---

## ⚡ Tech & Architecture

- **Stack**: HTML5, Tailwind CSS, Vanilla JS, Google Fonts (Inter + JetBrains Mono)
- **Design System**: Dark mode (`#050508`), glassmorphism, floating ambient orbs, terminal hero showcase, animated stat counters, and responsive mobile drawer
- **SEO & Social**: OpenGraph, Twitter Cards, JSON-LD Schema (Person), canonical tag, XML sitemap, and Google Analytics 4 integration
- **Deployment**: Zero build pipeline — instantly deployable to GitHub Pages

---

## 📁 Structure

```
.
├── index.html          # Main portfolio page
├── site.webmanifest    # Web manifest for mobile/PWA
├── robots.txt          # Crawler instructions
├── sitemap.xml         # XML sitemap
└── assets/             # Images, favicons, and resumes
```

## 💻 Local Preview

Open `index.html` in any browser or launch a local server:

```bash
# Using Python
python -m http.server 5500

# Or with Node
npx serve .
```
