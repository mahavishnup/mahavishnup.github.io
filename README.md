# Mahavishnu Ponnusamy — Portfolio

Personal portfolio website for Mahavishnu Ponnusamy, Senior Full-Stack Engineer.

🔗 **Live:** https://mahavishnup.github.io

## Tech Stack
- Plain HTML5 + Tailwind CSS CDN
- Zero build pipeline — deploys instantly to GitHub Pages
- Google Fonts (Inter) — fast, professional, ATS-matching font

## Local Development
Just open `index.html` in any browser. No `npm install`, no build step.

## Deployment (GitHub Pages)
1. Push this repo to GitHub as `mahavishnu-portfolio`
2. Go to **Settings → Pages → Branch: main → /root → Save**
3. Live at `https://mahavishnup.github.io/mahavishnu-portfolio`

## Sections
- **Hero** — Name, role, stat highlights, download resume CTAs
- **About** — Real background, no hype
- **Skills** — 6-category grid
- **Experience** — 2 jobs with verified metrics
- **Projects** — 4 real production projects
- **Education & Awards**
- **Contact** — Email + LinkedIn + GitHub + Linktree
